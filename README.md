This project is based on the book "Honeybee Democracy" by Thomas D. Seeley. In the book, Seeley explores the decision-making processes of honeybee swarms and how they collectively choose a new home. The project aims to simulate and analyze the behavior of honeybee swarms using genetic algorithms.
